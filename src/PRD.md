# 个人网站 PRD
## 1. 项目简介
本项目是基于 React + Vite + React Router 开发的简易SPA个人网站，包含首页与管理页面，实现前端无刷新路由跳转。

## 2. 项目目标
练习 React 前端路由，实现多页面切换，产出可线上部署的静态网站。

## 3. 页面与功能清单
1. 首页（路径 `/`）
- 展示网站标题与欢迎文字
- 提供跳转链接，进入管理页
2. 管理页（路径 `/admin`）
- 展示后台管理提示文字
- 提供返回首页的链接

## 4. 交互规则
- 使用 react-router-dom 的 `<Link>` 组件实现前端路由，跳转不刷新页面
- 开发环境支持热更新，修改代码页面自动更新

## 5. 不在本次范围内的功能
无登录校验、无后端接口、无数据库、无评论、无图片上传功能。
